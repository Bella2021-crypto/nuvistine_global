# Nuvistine Global

Official website for Nuvistine Global, a personal buying service based in Lagos, Nigeria.

Clients send a photo of the clothing or fabric they want. We find it in the Lagos markets, check the quality and fit, and ship it to them anywhere in the world.

## Features
- Four-step process: Send, Quote, Buy, Delivered
- Open pricing for African and international clients
- Request form that opens WhatsApp with the order details filled in
- Light and dark mode
